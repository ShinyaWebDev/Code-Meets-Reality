# EDR-001 — Separate Hub and Project Repositories

**Status:** Accepted  
**Date:** 2026-07

## Context

Code Meets Reality includes many different future applications and hardware experiments.

## Decision

Use Code Meets Reality as the portfolio, roadmap, knowledge base, and journal.

Keep each substantial application or firmware project in a separate repository.

## Consequences

Benefits:

- independent build and release history
- clearer dependencies
- focused issues and documentation
- cleaner portfolio navigation

Cost:

- links between repositories must be maintained
